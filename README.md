# Saraha - Backend

الـ API الخاص بتطبيق الرسائل المجهولة، بيتعامل مع الفرونت في [Saraha-F](https://github.com/AhmedMohemd/Saraha-F).

## المميزات

- إنشاء حساب وتسجيل دخول (بالإضافة لتسجيل الدخول بجوجل)
- تأكيد الإيميل واستعادة كلمة المرور
- إرسال رسائل مجهولة الهوية لأي مستخدم
- عرض وحذف الرسائل المستلمة بعد تسجيل الدخول
- إدارة البروفايل (صورة شخصية، صورة كفر، كلمة المرور، حذف الحساب)

## Tech Stack

Node.js, Express, MongoDB, Redis
